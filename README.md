# 🤖 AI Customer Support Email Auto-Responder

## Overview

An AI-powered customer support email automation workflow built using n8n and Large Language Models (LLMs). The workflow automatically classifies incoming customer emails, generates intelligent responses, performs quality checks, sends replies, archives processed emails, and logs activity into Google Sheets.

---

## Features

- 📩 Automatically detects incoming Gmail messages
- 🧠 AI-powered email classification
- 🚦 Urgency-based routing
- ✍️ AI-generated customer replies
- ✅ Quality checking before sending
- 📤 Automatic Gmail responses
- 🏷️ Archive and label processed emails
- 📊 Logs workflow activity to Google Sheets
- 🚨 Sends alerts for important emails

---

## Technologies Used

- n8n
- Gmail API
- Google Sheets
- Large Language Models (LLMs)
- AI Prompt Engineering
- Workflow Automation

---

## Workflow

The workflow follows these steps:

1. Gmail Trigger
2. Extract Email Data
3. AI Email Classifier
4. Parse AI Response
5. Urgency Router
6. AI Reply Generator
7. Quality Check
8. Send Gmail Reply
9. Archive & Label
10. Alert Manager
11. Log activity to Google Sheets
